# Automation Studio — 3D Lab

Experimental standalone 3D interactive workflow builder.

## Features
- **Self-Contained 3D Engine**: Runs entirely standalone with all scripts, configs, and runtime engines bundled in `lab/js/`.
- **Seamless Liquid Glass Magnifying Lens Cursor**: Real-time 1.65x optical magnification lens following fine pointers with spherical refraction and interactive action badge morphing.
- **Scroll-Shrinking Dock Bar**: Wide navigation bar at the top that smoothly shrinks into a compact floating glass pill when scrolling down.
- **Smooth Node Card Popup**: Tapping nodes opens the inspection card right next to the node in the viewport without any upward scroll jumps.
- **Translucent Textured Footer**: Frosted glass footer with subtle noise texture, glowing hairline accent, and live system readout counters.
